# ⏱️ Spring Data JPA Timestamp Application

A Spring Boot application demonstrating automatic timestamp management using Spring Data JPA and Hibernate annotations.

---

## 📌 Project Overview

This project showcases how to automatically maintain record creation and update timestamps using Hibernate annotations.

The application automatically stores:
- Record creation time
- Record update time

without requiring manual timestamp handling.

---

## 🧠 Concepts Covered

- Spring Boot
- Spring Data JPA
- Hibernate
- Automatic Timestamp Management
- Entity Lifecycle Handling
- JPA Entity Mapping
